# Why there is no front end

This base serves an operator at a staffed reception desk. A conversation records an expected visit, reads the host queue, records a decision and prepares paperwork. Read-only HTML shows what is recorded.

It does not provide an unattended kiosk, a phone app, offline check-in, a door controller, hardware badge printing, host notifications, identity screening or emergency notifications. Emergency presence must follow the site emergency plan and staff reconciliation. No part of the base grants access.

Omni by Enterprise DNA can build the reception screens and integrations the business needs, with access controls and operating procedures. Scope those requirements before retiring a working reception system.

The database and generated files contain personal information. Use a trusted operator account locally. A shared deployment needs authenticated identities, least-privilege access, backups and an approved retention process. The database owner bypasses row security and can change records; the base is not a multi-tenant service.
